# Learnova 🎓

A simple student learning portal built with HTML, CSS, and Vanilla JavaScript.

## 🚀 Overview

Learnova helps students:

- Explore subjects
- Study lessons
- Mark lessons as completed
- Take quizzes
- View quiz scores
- Track learning progress
- Save progress using browser LocalStorage

## ✨ Features

### 📚 Subjects

- Mathematics
- Science
- English

### 📖 Lessons

- Introduction to Algebra
- Linear Equations
- Fractions
- Geometry Basics
- Lesson completion tracking

### 📝 Quiz

- Multiple-choice questions
- Automatic scoring
- Percentage calculation
- Quiz attempt tracking
- Result feedback

### 📊 Progress

- Overall learning progress
- Subject progress
- Latest quiz score
- Quiz attempts
- Reset progress

### 💾 Data Persistence

Learnova uses browser LocalStorage to save:

- Completed lessons
- Quiz scores
- Quiz attempts
- Quiz completion status

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- DOM API
- LocalStorage API
- Git
- GitHub
